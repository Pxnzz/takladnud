# ตากหลาดนัด

เว็บแอปตลาดนัดสำหรับลูกค้าดูผังร้านและสำหรับร้านค้าจัดการโปรไฟล์/คำขอจอง สร้างด้วย Express, MariaDB และ frontend แบบ static ใน Express app เดียว

## เริ่มต้นใช้งาน

ติดตั้ง dependencies ด้วย `npm install` แล้วเริ่มระบบด้วย `npm start` จากนั้นเปิด `http://localhost:3104`.

เมื่อเริ่ม server จะสร้างตาราง `shops`, `markets`, `market_sessions`, `stalls`, `bookings` หากยังไม่มี จากนั้นหน้าเว็บเรียก `/api/health` เพื่อตรวจการเชื่อมต่อฐานข้อมูล

## หมายเหตุการตั้งค่า

ค่าพอร์ตและ MariaDB อยู่ตรง ๆ ใน `server.js` ตามข้อกำหนดโปรเจคนี้ ไม่ใช้ `.env`. ระบบนี้ยังไม่มี Admin และยังต้องมีข้อมูลตลาด/รอบ/แผงในฐานข้อมูลก่อนหน้าผังจะมีเนื้อหาให้แสดง; API จองมีแล้ว แต่ขั้นตอนเลือกแผงและส่งคำขอจาก UI ยังอยู่ระหว่างพัฒนา

สำหรับ production ต้องให้บริการผ่าน HTTPS เพื่อให้ session cookie ใช้ `Secure`; session ในรอบเริ่มต้นเก็บใน memory จึงถูกล้างเมื่อ server restart และเหมาะกับการทดลอง/MVP เท่านั้น
